# Why Are Linear RNNs More Parallelizable?

Source-faithful CPU reproduction for ICML 2026 paper `29sn1uqWn3`,
*Why Are Linear RNNs More Parallelizable?* (arXiv `2603.03612`).

The target scope is five anchored theorem/construction claims: the PNC1 upper
bound, near-log-depth circuit consequence, log-precision connectivity
construction, poly-precision separation, and four-layer DPLR/WFA simulation.
The neural-training experiment is deliberately excluded: it is the sixth claim
and no source training protocol is released.
