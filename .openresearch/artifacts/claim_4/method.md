# Claim 4 method

The certificate proves a gapped base-4 stack representation by induction,
constructs exact ReLU head/nonempty observers, and checks affine push/pop
identities. A one-hot ReLU selector realizes the fixed finite transition table.
The denominator after T steps is at most `4^T`, so the state needs O(T) bits.

For a fixed P-complete language with runtime `C n^c`, an FO-definable padded
language supplies `C n^c` clock symbols. The RNN stores the input on stacks and
uses one padding token per simulated transition. P-membership and P-hardness
give P-completeness.

The independent checker exhausts every binary stack through depth 14. The
negative control measures the paper's base-2 threshold margin through depth 64
and requires it to vanish.
